2. Lorsque vous avez terminé, essayez de définir les valeurs des variables du paragraphe précédent sur une seule ligne comme var1, var2 = value1, value2 (la première variable reçoit la première valeur, etc.).

Bien que Python reste un langage dynamiquement typé, ce qui signifie que vous n'avez pas à spécifier de types pour les variables, l'incorporation d'annotations de type, en particulier dans les grands projets ou lorsque vous travaillez en équipe, peut améliorer de manière significative la qualité du code et la maintenabilité. Il convient de noter que les annotations de type sont facultatives et que Python n'impose pas un typage strict; elles servent principalement d'aide au développement et d'outil de documentation.

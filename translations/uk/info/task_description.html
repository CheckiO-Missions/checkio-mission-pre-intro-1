1. У цій найпершій місії вам просто потрібно допомогти нашій купці cyborgs подружитися! Подивіться приклад у редакторі, оголосіть дві змінні robots, droids та встановіть їхні значення цілими числами 2, 5 відповідно. Якщо у вас виникнуть труднощі, зверніться до підказок під описом.

2. Після цього спробуйте задати значення для змінних з попереднього пункту в одному рядку на кшталт var1, var2 = value1, value2 (перша змінна отримує перше значення і т.д.).

Хоча Python залишається динамічно типізованою мовою, тобто вам не потрібно вказувати типи для змінних, включення анотацій типів, особливо у великих проектах або при роботі в команді, може значно підвищити якість коду та його ремонтопридатність. Варто зазначити, що анотації типів є необов'язковими, і Python не вимагає суворої типізації; вони слугують, насамперед, як допоміжний інструмент для розробки та документування.

3. Для цілих чисел використовуйте тип int. Спробуйте переписати завдання з першого абзацу з анотаціями типів.
